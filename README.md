# NixNet-Desktop
اپ دسکتاپ ویندوز برای مدیریت و اتصال سرویس‌ها، ساخته‌شده با Electron و هسته‌ی Xray.

با وارد کردن کد سرویس، سرورها را با نوار حجم، روزهای باقی‌مانده و پینگ TCP هر سرور می‌بینید و با یک کلیک وصل می‌شوید.

امکانات
تم تاریک و روشن، با لوگوی پروژه به‌عنوان آیکن برنامه و صفحه‌ی ورود
فارسی (راست‌به‌چپ) و انگلیسی با دکمه‌ی تعویض زبان در بالای پنجره
نمایش سرویس‌ها شامل نوار حجم، روز باقی‌مانده و پینگ TCP هر سرور
دو حالت اتصال: پروکسی سیستم و TUN
بازگردانی تنظیمات: تنظیمات قبلی ویندوز ذخیره می‌شود و بعد از قطع اتصال یا کرش برنامه برمی‌گردد
تأیید واقعی اتصال: پیام «متصل شد» فقط وقتی نمایش داده می‌شود که هسته بالا آمده، شبکه تنظیم شده و سه تست پشت‌سرهم از داخل تونل موفق بوده باشد. بعد از آن پینگ واقعی نمایش داده می‌شود و هر ۸ ثانیه دوباره سنجیده می‌شود. اگر تست‌ها شکست بخورند، وضعیت به «اتصال ناپایدار» تغییر می‌کند.
